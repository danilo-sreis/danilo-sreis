## About me

I'm a front-end developer at **Shakers**, a Shopify-focused agency, where I build and maintain custom themes for e-commerce brands. I work in a squad alongside designers and other developers, taking projects from Figma to a live storefront and making sure what ships matches the design on desktop, tablet and mobile.

Most of my work is Shopify theme development in Liquid: custom sections and blocks with JSON schema, powered by metaobjects and metafields, so merchants can manage their content without touching code. I also build interactive components for storefronts and care about keeping themes fast and maintainable. One example is migrating sections from dynamic to static blocks to shrink JSON templates, always following the repository's naming and structure conventions so the codebase stays consistent across projects.

For me, a theme is only done when the client can actually use it. That's why I also write documentation and record walkthrough videos that let clients and teammates configure everything on their own.

Outside of work, I'm studying Multiplatform Software Development at Fatec Diadema, going deeper into Shopify theme architecture and improving my English at ONG Cidadão Pró-Mundo. I'm curious about other cultures and always happy to talk with people from other countries.
